# Orka 1.3.3 — subscription-backed desktop routes

Model-less desktop routes now use the selected installed client's subscription
login and default model. `provider: openai` selects Codex; `provider: anthropic`
selects Claude. Verified preflight checks that the client exists without making
a provider request, and the controller no longer requires an API model or key.

Subscription children are launched without Orka's metered API gateway. Inherited
API keys, custom base URLs, and alternate Claude cloud-provider selectors are
removed from their environment so an intended subscription run cannot silently
become API-billed work.

API dollar/token accounting is unavailable for subscription turns. Concurrency,
attempt ceilings, bounded review and repair cycles, worker lifetime, repository
leases, isolated worktrees, CI requirements, and merge-on-green remain enforced.
Explicit-model desktop routes retain the existing metered gateway behavior.
